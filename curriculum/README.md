# SAGAN curriculum map

This is the proposed learning map. Each lesson should eventually include: learning goals, plain-language explanation, key vocabulary, an accessible text alternative for every visual, an activity, a short knowledge check, references/data provenance, and optional sonification.

See [`LESSON_TEMPLATE.md`](LESSON_TEMPLATE.md) in this directory to start writing a new lesson.

## Path 1 — Start here
1. What is astronomy?
2. How astronomers observe the universe
3. Scientific questions, evidence, and uncertainty
4. Scales, distances, and units
5. How to use this learning platform

## Path 2 — Light and spectra
6. Light as electromagnetic radiation
7. Wavelength, frequency, and energy
8. Color and filters
9. Reading a simple spectrum
10. Telescopes and detectors

## Path 3 — The Sun and stars

13. Star mass and stellar lifetimes

## Dataset policy

Do not bundle real observations without checking source terms, attribution, and redistribution rules. Each dataset lesson must document mission/instrument, archive, dataset identifier, time span, units, processing level, access date, known caveats, and license/terms. Keep synthetic teaching data clearly labeled as synthetic. Potential source catalogues include NASA mission archives and the Mikulski Archive for Space Telescopes (MAST); integrations must be verified before release.
