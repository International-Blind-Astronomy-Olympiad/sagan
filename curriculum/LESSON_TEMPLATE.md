# SAGAN lesson template

Use this template to draft a new chapter for SAGAN. Fill in every section. Remove instructional notes (lines in *italics*) before submitting your pull request.

Open a GitHub issue with your proposed topic before starting a large draft so maintainers can give early feedback and avoid duplicated effort.

## 10. Accessibility checklist

*Complete before submitting.*

- [ ] All visuals have a text description in the lesson body.
- [ ] Technical terms are defined in plain language on first use.
- [ ] Sentences are generally under 25 words.
- [ ] The chapter was read aloud (or with a screen reader) and made sense.
- [ ] Any audio content has an equivalent text description.
- [ ] Colour is not the only way information is conveyed.
- [ ] Data marked "synthetic" everywhere it appears (if applicable).
- [ ] Sources cited for all scientific claims.
