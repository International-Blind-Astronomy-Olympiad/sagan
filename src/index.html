    BUILT TO LEARN TOGETHER

    A more accessible way into astronomy

    SAGAN aims to make astronomy understandable through plain language, structured chapters, meaningful descriptions, and optional audio. We welcome students, educators, astronomers, accessibility testers, and open-source contributors from around the world.

    Learn step by step

    Build from basic concepts toward light curves, exoplanets, stellar science, and astronomy data.

    More than a picture

    Charts have text descriptions, controls work with a keyboard, and audio is optional.

    Open to contributors

    Help improve lessons, accessibility, scientific references, translations, and sonification experiments.

    Scientific note: SAGAN is in development. This prototype does not connect to live mission archives and does not currently implement a trained GAN model. Scientific lessons and dataset integrations need review before being treated as authoritative.
